UNDER THE HOOD

무슨 차이일까요?

BLOCKING

점원이 창고 답을 기다리며 멈춤

async def product():
    data = get_product()  # time.sleep(2)
    return data

이벤트 루프 스레드가 잠들어 다른 주문과 상태 확인도 처리하지 못합니다.

ASYNC

기다리는 동안 다음 주문을 접수

async def product():
    await asyncio.sleep(2)
    return data

await에서 제어권을 돌려주므로 여러 대기 시간이 서로 겹칩니다.

THREAD OFFLOAD

기존 창고 전화는 다른 직원에게

async def product():
    data = await asyncio.to_thread(
        get_product
    )
    return data

동기 라이브러리를 바꿀 수 없다면 별도 작업 스레드에서 실행합니다.

핵심 기억하기

async def라고 쓰는 것만으로 모든 코드가 비동기가 되지는 않습니다.
