합격 기준은 60점

RESULT

리스트 · for · 나머지 연산 %

리스트에서 짝수 찾기

정수 5개를 모아 리스트를 만들고, 2로 나눈 나머지가 0인 숫자를 찾습니다.

RESULT
입력한 리스트와 짝수가 여기에 표시됩니다.

추가 과제: 홀수만 출력하도록 조건을 바꾸고 짝수의 개수도 구해보세요.

Python 예제 보기
scores = []
for i in range(5):
    score = int(input(f"{i + 1}번째 숫자: "))
    scores.append(score)

for number in scores:
    if number % 2 == 0:
        print(number)
중첩 for · range · 출력 순서

반복문으로 만드는 구구단

두 반복문을 겹쳐 구구단을 만듭니다. 원래 예제의 두 출력 방식을 비교해보세요.

RESULT
출력 방식을 선택하고 구구단을 만들어보세요.

추가 과제: Python에서 원하는 단을 입력받아 1~9까지 출력하세요. range(a, b)는 a부터 b−1까지 생성합니다.

Python 예제 보기
# 연습 A: 한 행에 같은 단을 출력
for dan in range(2, 5):
    for i in range(1, 5):
        print(f"{dan} x {i} = {dan * i}", end="\t")
    print()

# 연습 B: 한 행에 2~9단을 출력
for multiplier in range(1, 10):
    for dan in range(2, 10):
        print(f"{dan} x {multiplier} = {dan * multiplier}", end="\t")
    print()

숨겨진 숫자를 찾아보세요

1~100 사이의 정수를 골랐습니다. 힌트를 읽고 다음 숫자를 입력하세요.

RESULT
첫 번째 숫자를 입력하세요. 시도 횟수: 0

    추가 과제: Python 게임의 시도를 7번으로 제한하고, 실패하면 정답을 공개해보세요.

    Python 예제 보기
    import random

answer = random.randint(1, 100)
count = 0
while True:
    guess = int(input("1~100: "))
    if not 1 <= guess <= 100:
        continue
    count += 1
    if guess > answer:
        print("정답보다 큽니다.")
    elif guess < answer:
        print("정답보다 작습니다.")
    else:
        print(f"정답! 총 시도 횟수: {count}")
        break
